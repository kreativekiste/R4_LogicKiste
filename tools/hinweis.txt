HINWEIS: Hier muss die 'arduino-cli.exe' liegen

Damit die R4_LogicKiste Code auf deinen Arduino übertragen kann, wird das Tool 'arduino-cli' benötigt.

ANLEITUNG:
1. Lade die passende Version für dein Betriebssystem hier herunter:
   https://arduino.github.io/arduino-cli/latest/installation/
   (Oder direkt bei GitHub: https://github.com/arduino/arduino-cli/releases)

2. Entpacke die Datei (falls es ein .zip ist).

3. Kopiere die 'arduino-cli.exe' genau in diesen Ordner (/tools/).

Die 'bridge.py' ist so eingestellt, dass sie in diesem Verzeichnis nach der Datei sucht.
