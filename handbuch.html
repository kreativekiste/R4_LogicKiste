Bedienungsanleitung & Block-Referenz

Willkommen im Handbuch der Arduino R4_LogicKiste. Hier findest du eine Übersicht aller verfügbaren Blöcke, deren Parameter und die Information, ob sie mit älteren Arduino R3 Boards kompatibel sind.

📁 Kategorie: Board

Hauptrahmen arduino_main

Beschreibung: Der unzerstörbare Grundrahmen für jedes Programm. Enthält die Bereiche Global, Setup und Loop.
R3 kompatibel: JA

Pin-Interrupt board_pc_interrupt

Beschreibung: Überwacht einen digitalen Pin im Hintergrund. Löst sofort eine Aktion aus, wenn sich der Zustand ändert (RISING, FALLING, CHANGE).
R3 kompatibel: JA

Kommentar kommentar

Beschreibung: Erzeugt ein Kommentar-Textfeld im Blockly-Workspace, das als reiner Infotext direkt in den C++ Code exportiert wird.
R3 kompatibel: JA

⚙️ Kategorie: Steuerung & Logik

Wenn / Falls logic_if

Beschreibung: Führt den inneren Code nur aus, wenn die verknüpfte Bedingung wahr (true) ist.
R3 kompatibel: JA

Wenn / Sonst logic_if_else

Beschreibung: Erweitert die Bedingung um einen "Sonst"-Zweig, falls die Prüfung falsch (false) ergibt.
R3 kompatibel: JA

Zählschleife loop_for

Beschreibung: Wiederholt Codeblöcke eine exakte Anzahl von Malen unter Verwendung einer Zählvariable.
R3 kompatibel: JA

Dauernd Solange ard_loop_while

Beschreibung: Wiederholt den Code im inneren Bereich ununterbrochen, solange die Bedingung erfüllt bleibt.
R3 kompatibel: JA

Weiche (Switch) ard_switch

Beschreibung: Prüft eine Variable auf verschiedene feste Werte (Cases), um lange verschachtelte Wenn-Abfragen zu umgehen.
R3 kompatibel: JA

🌡️ Kategorie: Sensoren

Digitaler Eingang ard_digital_unpack

Beschreibung: Liest den Zustand (An/Aus) eines digitalen Pins ein. Unterstützt die internen Pull-Up Widerstände.
R3 kompatibel: JA

Analoger Eingang ard_analog_in

Beschreibung: Liest eine analoge Spannung an den Pins A0-A5 und wandelt sie in einen Zahlenwert von 0 bis 1023 um.
R3 kompatibel: JA

Temperatur DS18B20 ds18b20_temp

Beschreibung: Fragt die präzise Temperatur eines wasserdichten DS18B20 One-Wire Sensors in °C ab.
R3 kompatibel: JA

Ultraschall HC-SR04 hc_sr04_distanz

Beschreibung: Misst berührungslos Entfernungen im Bereich von 2cm bis 400cm mittels Schalllaufzeit.
R3 kompatibel: JA

🚨 Kategorie: Aktoren & Ausgänge

Digital Schalten ard_digital_write

Beschreibung: Schaltet einen digitalen Ausgangskanal hart EIN (5V/3.3V) oder AUS (0V).
R3 kompatibel: JA

PWM / Dimmen ard_analog_write

Beschreibung: Gibt ein Pulsweitensignal (0 bis 255) aus, um LEDs zu dimmen oder Motorgeschwindigkeiten zu regeln.
R3 kompatibel: JA

Servo Motor ard_servo_move

Beschreibung: Dreht einen Standard-Servomotor auf einen exakten Winkel zwischen 0° und 180°.
R3 kompatibel: JA

Ton Erzeugen ard_tone_pitch

Beschreibung: Erzeugt auf einem Piezo-Summer eine frei definierbare Tonfrequenz in Hz für eine bestimmte Dauer.
R3 kompatibel: JA

🖥️ Kategorie: OLED Display (SSD1306)

OLED Setup ard_oled_setup

Beschreibung: Initialisiert das OLED-Display via I2C. Erlaubt die Auswahl zwischen 0.96 Zoll (128x64) und 0.91 Zoll (128x32) sowie der I2C-Taktgeschwindigkeit.
R3 kompatibel: JA

Schriftart setzen ard_oled_set_font

Beschreibung: Ändert die Textskalierung (Größe) für alle nachfolgenden Textausgaben auf dem Display.
R3 kompatibel: JA

Display löschen ard_oled_clear

Beschreibung: Leert den kompletten Bildschirminhalt (löscht den Puffer und aktualisiert das Display).
R3 kompatibel: JA

Text schreiben ard_oled_print

Beschreibung: Schreibt Text oder Zahlen an der aktuellen Cursorposition auf das Display (optional mit automatischem Zeilenumbruch).
R3 kompatibel: JA

Text an X/Y ard_oled_print_xy

Beschreibung: Setzt den Cursor pixelgenau auf die Koordinaten X und Y und schreibt dort den Text oder den Inhalt einer Variable hin.
R3 kompatibel: JA

Formen zeichnen ard_oled_draw_shape

Beschreibung: Zeichnet geometrische Formen pixelgenau auf das Display. Die Parameter passen sich der gewählten Form an:
Gewählte Form X / Y B / X2 / Rad H / Y2 X3 / Y3
Linie Startpunkt (X/Y) Endpunkt X2 Endpunkt Y2 - (wird ignoriert)
Rechteck (Rand / Voll) Obere linke Ecke Breite (B) Höhe (H) - (wird ignoriert)
Kreis (Rand / Voll) Mittelpunkt (X/Y) Radius (Rad) - (wird ignoriert) - (wird ignoriert)
Dreieck (Rand / Voll) Punkt 1 (X/Y) Punkt 2 X2 Punkt 2 Y2 Punkt 3 (X3/Y3)
R3 kompatibel: JA

🌐 Kategorie: Netzwerk & WebServer

WiFi Verbinden web_wlan_setup

Beschreibung: Initialisiert das integrierte WLAN-Modul und verbindet das Board mit dem lokalen Router (SSID + Passwort).
R3 kompatibel: NEIN

Status / Verbindung web_status_read

Beschreibung: Gibt zurück, ob das Board erfolgreich mit dem Router verbunden ist.
R3 kompatibel: NEIN

Daten zum Web web_digital_write / web_analog_write

Beschreibung: Sendet Sensorwerte oder Schalter-Zustände aktiv an die Webseite, die vom Board gehostet wird.
R3 kompatibel: NEIN

Daten vom Web web_digital_read / web_analog_read

Beschreibung: Empfängt Befehle von der Webseite (z.B. Button auf dem Smartphone gedrückt), um Hardware am Arduino zu schalten.
R3 kompatibel: NEIN
